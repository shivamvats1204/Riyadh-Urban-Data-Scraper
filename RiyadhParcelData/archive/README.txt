# Riyadh Urban Parcel Dataset (Full Version – 1.2M+ Rows)

## 📌 OVERVIEW

This dataset contains over 1.2 million parcel-level records from Riyadh, Saudi Arabia. It is designed for use in Machine Learning, GIS (Geographic Information Systems), urban planning, and data analysis applications.

The dataset provides real-world structured data with geospatial attributes, zoning classifications, and land use information.

## 📊 DATASET FEATURES

• 1,200,000+ records
• Latitude & Longitude (WGS84 format)
• Zoning classifications
• Land use categories
• Parcel-level attributes
• Real-world, non-synthetic data

## 📌 COLUMN DESCRIPTION (Example)

Note: Column names may vary slightly depending on version.

• parcel_id       → Unique identifier for each parcel
• latitude        → Geographic latitude
• longitude       → Geographic longitude
• zoning_type     → Zoning classification
• land_use        → Type of land usage
• area_sq_m       → Parcel area in square meters
• building_rules  → Regulatory constraints

Refer to data_dictionary.csv for full details.
